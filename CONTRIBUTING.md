# Contributing

1. Open an issue describing the decision path, data rights, and measurable acceptance test.
2. Keep the runtime non-generative and fail closed on contract mismatch.
3. Add tests for deterministic output, bounds, abstention, and malformed artifacts.
4. Run `ruff check .` and `pytest` before opening a pull request.

Synthetic data is welcome when clearly labeled. Do not submit confidential enterprise data
or outputs from models whose terms prohibit distillation.
