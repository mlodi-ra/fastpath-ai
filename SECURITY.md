# Security policy

FastPath AI is alpha software. Do not use it as the sole control for safety-critical,
security-critical, financial, medical, or regulated decisions.

Report vulnerabilities privately through GitHub Security Advisories. Do not include
customer data, credentials, model artifacts containing confidential labels, or production
logs in a report.

Model artifacts are code-adjacent inputs. Pin their digest, restrict write access, validate
their contract fingerprint, and load them only from trusted sources.
